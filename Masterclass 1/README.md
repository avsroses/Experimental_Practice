# Arduino and Bluetooth

## Hardware

- Arduino UNO R4 Board
- DFRobot Gravity: 130 DC Motor Module
- Button component for Arduino
- Potentiometer component for Arduino
  
## Software

- Arduino IDE

## Explanation

The code uploaded to the Arduino allows for the value of the motor speed to be written from an app on a phone, or another Arduino, over Bluetooth.
